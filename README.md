# Solar Power Plant Analysis

An end-to-end data analytics and predictive modeling project that analyzes solar energy generation efficiency, detects equipment failure anomalies, and forecasts power output.

## Features
- **Exploratory Data Analysis (EDA):** In-depth evaluation of inverter yield, daily power generation, and irradiation metrics.
- **Anomaly Detection:** Identifies faulty or underperforming solar panels/inverters.
- **Predictive Modeling:** Machine learning models forecasting AC/DC power output based on weather and sensor data.

## Tech Stack
- **Language:** Python 3.x
- **Libraries:** Pandas, NumPy, Matplotlib, Seaborn, Scikit-Learn
- **Tools:** Jupyter Notebook
